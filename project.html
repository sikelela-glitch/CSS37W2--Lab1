Proposed Team Project: FleetPulse Telemetry

Project Description

FleetPulse is a real-time fleet vehicle tracking and diagnostics system designed to process telemetry data using WebSockets, Node.js, and a microservices backend architecture.

Key Objectives

  • Real-time GPS coordinates processing with low latency.
  • Automated alert generation for engine diagnostics.
  • Interactive administrative dashboard for fleet management.
